# COA Teleport

In-game teleport browser for Conquest of Azeroth (WoW 3.3.5a). WoW-style window: pick a category, search, click a place and it runs `.go xyz` for you. About 2,350 places: stock zones, dungeons/raids, CoA custom maps and a dedicated **Fading Islands** tab (32 places).

- Needs a **GM account** (it uses `.go xyz`).
- Features: search box, favourites, minimap button, `/tp` or `/teleports` to open.

## Install
Copy the `CoA_Teleports` folder into `Interface\AddOns\` of your client and start the game (`/reload` if already running).

Place list generated from the CoA `game_tele` table (2026-11-05).
